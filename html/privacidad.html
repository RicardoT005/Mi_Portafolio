Aviso de privacidad

Última actualización: 25 de octubre de 2026

1. Responsable

El responsable del tratamiento de los datos personales que se puedan recabar a través de este sitio es Ricardo Torres, bajo la marca MultiSoftCreations.

2. Datos que se recaban

En la versión actual del sitio (estática):

  • No se recaban datos personales mediante formularios de contacto.
  • El contacto principal se realiza a través de WhatsApp Business, servicio de terceros (Meta).
  • Pueden generarse datos de navegación habituales (dirección IP, tipo de navegador, páginas visitadas) si el alojamiento (GitHub Pages) o herramientas de análisis los registran.

Cuando se implemente un formulario con almacenamiento (por ejemplo Firebase), se actualizará este aviso indicando exactamente qué datos se solicitan, con qué finalidad y durante cuánto tiempo se conservan.

3. Finalidad

Los datos que eventualmente se recaben se utilizarán únicamente para responder a solicitudes de información o cotización relacionadas con los servicios ofrecidos. No se utilizarán para envíos publicitarios no solicitados.

4. Transferencias y terceros

El sitio puede alojarse en GitHub Pages. WhatsApp es un servicio de Meta Platforms. Cualquier proveedor adicional (Firebase, servicios de correo, etc.) se indicará en este aviso cuando se integre.

5. Derechos ARCO

De acuerdo con la legislación mexicana aplicable, puedes ejercer tus derechos de Acceso, Rectificación, Cancelación y Oposición respecto a tus datos personales. Para ello, contacta a través de los medios indicados en la página de Contacto.

6. Cambios

Este aviso puede actualizarse cuando se incorporen nuevas funcionalidades que impliquen tratamiento de datos. La fecha de la última actualización aparecerá al inicio de este documento.

Este texto describe la operación real del sitio en su estado actual. No constituye asesoría legal completa. Se recomienda revisar la legislación vigente y, si es necesario, obtener asesoría profesional.
