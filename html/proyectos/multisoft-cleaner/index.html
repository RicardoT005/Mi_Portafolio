Descripción

MultiSoftCleaner es una utilidad de escritorio en Python orientada a escaneo, duplicados y limpieza. Se publica como demo gratuita para pruebas y feedback, no como producto terminado.

Cómo probar la demo

  1. Ten instalado Python 3.10+.
  2. Clona el repositorio:
    git clone https://github.com/RicardoT005/MultiSoftCleaner_V2.1.1-free.git
  3. Entra a la carpeta:
    cd MultiSoftCleaner_V2.1.1-free
  4. Instala dependencias:
    pip install -r requirements.txt
  5. Ejecuta desde la raíz del proyecto:
    python main.py

En Windows, win10toast es opcional. Si falla la instalación, la app puede seguir abriendo sin notificaciones del sistema.
