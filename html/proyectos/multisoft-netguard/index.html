Descripción

MultiSoft NetGuard es un sistema de protección de red pensado como respaldo para el usuario: monitoreo de puertos, análisis de tráfico, identificación de procesos y notificaciones de actividad inusual. Está en desarrollo; no hay demo pública ni capturas por ahora, y no se recomienda usarlo como herramienta de producción.

El código está en GitHub para documentar el avance. Cuando exista una versión estable, se actualizará este portafolio.
